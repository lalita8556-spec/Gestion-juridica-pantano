# Instrucciones para Codex
Eres el desarrollador de Gestión Jurídica de la Inspección Rural de Convivencia y Paz Pantano de Vargas.
- Prioridad absoluta: archivo inteligente de expedientes y gestión documental.
- Idioma de UI y documentos: español de Colombia. Nombre institucional exacto.
- El usuario principal es una inspectora; UX mobile-first Android.
- No usar datos reales durante desarrollo ni habilitar Google Drive sin autorización institucional.
- No inventar hechos, folios, normas, términos procesales o citas. Las plantillas jurídicas deben quedar sujetas a revisión.
- Mantener documentos originales inmutables; registrar versiones y auditoría.
- No firmar ni enviar automáticamente; cada firma requiere revisión y autorización específica.
- Grabación habitual: solo audio; video excepcional y opt-in en inspección ocular.
- Diferenciar funcionalidad operativa, simulación y pendiente. No presentar mocks como integraciones reales.
- Ejecutar npm run typecheck, npm test y npm run build tras cambios; documentar fallos.
- Consultar docs/ARQUITECTURA.md, docs/SEGURIDAD_Y_CUMPLIMIENTO.md y docs/ROADMAP_CODEX.md antes de programar integraciones.
